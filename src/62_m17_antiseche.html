La suite du parcours

  1. Un projet fil rougeTaskFlow : une app de tâches qui mobilise chaque module de ce cours (détails ci-dessous).
  2. TypeScripttyper props, état et événements. Tes réflexes de C# t'y aideront beaucoup.
  3. React Queryles données serveur : cache, rafraîchissement, mutations. Il remplacera tes fetch dans des effets.
  4. Le routageReact Router ou TanStack Router : pages, paramètres d'URL, navigation.
  5. Formulaires et testsreact-hook-form + zod, puis Vitest et Testing Library.
  6. Un frameworkNext.js ou React Router en mode framework : rendu serveur et Server Components.

Le projet TaskFlow, étape par étape

Construis-le dans ton bac à sable Vite, et branche-le sur une petite API FastAPI ou ASP.NET que tu écris toi-même. Tu verras les deux côtés du contrat. Avance dans l'ordre : chaque étape s'appuie sur la précédente.
